When it breaks

It will break. That’s normal.

My page is blank

Open the console (Cmd Option J on a Mac, Ctrl Shift J elsewhere), copy the red error, and send it with:

I got this error. Fix it and explain what was wrong:
Access to fetch … has been blocked by CORS policy

That API doesn’t let web pages call it. Every API in Live data does.

Mixed Content: … requested an insecure resource 'http://…'

Change http:// to https://, or pick another API.

The AI keeps asking for an API key

Tell it: “This API needs no key. Don’t add one.”

Every fix makes it worse

Go back to the last version that worked (Canvas and GitHub both keep history), then ask for one small change.

404 · There isn’t a GitHub Pages site here.

Wait a minute. The file must be named index.html and sit in the top folder of the repo.

Never paste passwords, API keys or personal info into an AI or your code. Nothing today costs money: if a site asks for a card, stop.
