Lane 1 · Build it now

About 3 minutes No new accounts

You’ll use Gemini’s Canvas, which writes your app and runs it right next to the chat. Tick steps off as you go; this page remembers.

  1. Open Gemini with your school account 0:30

    Go to gemini.google.com and sign in with your school Google account.

  2. Turn on Canvas 0:15

    In the message box, open Tools and pick Canvas. That’s the mode that builds apps you can see and click.

  3. Warm up with the instructor’s demo 1:00

    Paste this, send it, then click Preview. You just built a website.

    Make a yellow website with a header that says "Agentic Workshop".

  4. Paste your real starter prompt 1:00

    Grab one from the four questions, build your own with the pitch builder, or press Copy starter prompt on any card in Live data. Your app will pull real data on its first try.

  5. Make it yours, one change at a time

    Ask for one thing per message: “Make the headline huge.” “Add a map.” “Use the SDG 13 green, #3F7E44.” If something breaks, see When it breaks.

  6. Share it

    Use Share in Canvas to get a link. If your school limits sharing, do Lane 2 to give it a real web address.

Gemini isn’t turned on for your account? Use ChatGPT instead: its Canvas can also run HTML apps. ChatGPT is for ages 13+, and if you’re under 18 you need a parent’s or guardian’s permission. If neither works, pair up with a classmate. Two people on one app is how real teams work anyway.

Lane 2 · Put it on the internet

About 5 minutes GitHub account, age 13+

GitHub is where developers keep their code, work in teams and publish websites. GitHub Pages turns your file into a real link anyone can open.

  1. Make a free GitHub account 2:00

    Sign up at github.com/signup with an email you can check right now, then enter the code GitHub emails you. Pick a username you’d be happy to show a future employer.

  2. Create a repository 0:30

    Click + (top right) → New repository. Name it after your app (like birthday-heat), choose Public, tick Add a README file, then Create repository.

  3. Add your app 1:00

    In Canvas, switch to the Code view and copy everything. On GitHub: Add file → Create new file, name it exactly index.html, paste, then Commit changes.

  4. Turn on GitHub Pages 0:30

    Settings → Pages. Under Build and deployment, set Source to Deploy from a branch, pick main and / (root), then Save.

  5. Open your link 1:00

    Wait about a minute and refresh the Pages screen. Your app is live at https://YOUR-USERNAME.github.io/REPO-NAME/. Text it to someone.

  6. Working in a team? Add your teammates

    Settings → Collaborators → Add people. To update the app later, open index.html, click the pencil, paste the new version and commit. The site updates in about a minute, and GitHub keeps every old version in case you need to go back.

Other ways to publish: Netlify Drop (13+) lets you drag a folder with your index.html onto the page. To keep the site, claim it with a free Netlify account within about an hour. Vercel (16+) connects to your GitHub repo and republishes automatically every time you commit.

Lane 3 · The pro setup

About 10 minutes Needs Lane 2’s GitHub repo

A full code editor in your browser with an AI agent that can read, write and fix your files. This is close to how professional developers work.

  1. Open a Codespace 2:00

    In your repo, click the green Code button → Codespaces → Create codespace on main. VS Code opens in your browser. Free accounts get 120 core-hours a month, which is about 60 hours on the standard machine.

  2. Open Copilot in Agent mode 1:00

    Open the chat panel (the Copilot icon at the top, or Ctrl+Alt+I; Ctrl+Cmd+I on a Mac) and switch the mode to Agent. Copilot Free comes with every GitHub account and has a monthly usage limit.

  3. Give it your starter prompt 3:00

    Paste your prompt. The agent edits index.html for you. Read each change before you click Keep, because you’re the architect.

  4. Preview it 1:00

    Open the terminal (Ctrl+`) and run the line below, then click Open in Browser when it pops up.

    python3 -m http.server 8000

  5. Commit and publish 1:00

    Open the Source Control panel, write a short message about what changed, then click Commit and Sync. If you turned on Pages in Lane 2, your live site updates in about a minute.

  6. After today: get the student pack

    Apply for GitHub Education with your school email or student ID (13+). Approval can take a few days. Then you get Copilot Student for free, plus extra Codespaces hours.

When it breaks

It will break. That’s normal.

Professional developers spend a lot of their day on exactly these problems.

My page is blank

Open the browser console: Cmd+Option+J on a Mac, Ctrl+Shift+J on Windows or a Chromebook. Copy the red error and send it to your AI with: “I got this error. Fix it and explain what was wrong.”

It says “blocked by CORS policy”

That API doesn’t allow web pages to call it. Pick one from Live data instead: every API there was tested in a browser.

It says “mixed content”, or nothing loads on my live site

Your app is calling an http:// address. Websites served over https can only fetch https URLs, so change it to https:// or pick another API.

The AI keeps asking for an API key

Tell it: “This API needs no key. Don’t add one.” Never paste a real key into a public app.

Every fix makes it worse

Stop and go back to the last version that worked: Canvas keeps a version history, and GitHub keeps every commit. Then ask for one small change at a time.

The data looks weird

Ask: “Log the first item with console.log and explain each field in plain English.” Then tell the AI which fields you actually want.

My GitHub Pages link shows 404

Give it a minute. Check that the file is named exactly index.html (lowercase), sits in the top folder of the repo, and that Settings → Pages says your site is live.

Stay safe

Never put passwords, API keys or personal details (yours or anyone else’s) into an AI chat or into your code. Public repos and websites can be seen by anyone. And if any site asks for a credit card, stop: nothing today costs money.
