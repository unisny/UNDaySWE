Your first fetch

Ten lines, live data.

Paste this into your browser console (Cmd+Option+J on a Mac, Ctrl+Shift+J on Windows or a Chromebook) and press Enter. Or paste it into your AI and ask it to turn it into a real app.

JavaScript

// Live earthquakes from the last 24 hours. No key needed.
fetch("https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson")
  .then((response) => response.json())
  .then((data) => {
    const quakes = data.features;
    console.log("Earthquakes in the last 24 hours: " + quakes.length);
    const biggest = quakes.reduce((a, b) => (b.properties.mag > a.properties.mag ? b : a));
    console.log("Biggest: M" + biggest.properties.mag + ", " + biggest.properties.place);
  });

Python

# Same data in Python. Run: pip install requests
import requests

url = "https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson"
quakes = requests.get(url).json()["features"]
print("Earthquakes in the last 24 hours:", len(quakes))

biggest = max(quakes, key=lambda q: q["properties"]["mag"] or 0)
print("Biggest: M", biggest["properties"]["mag"], biggest["properties"]["place"])
Lesson from testing

APIs break. Always have a backup.

Some popular “free API” lists are out of date. These didn’t make the cut when we tested them, and here’s what to use instead.

  • Bored API: the original site shut down, and the copy that’s still online blocks web pages (no CORS). Try Open Trivia DB or TheMealDB for something to do.
  • Free Dictionary API: was down when we tested. Use Wiktionary or Datamuse.
  • Universities API and ip-api: only work over plain http://, which browsers block on https websites. For location, use the browser’s own navigator.geolocation (it asks permission first) or let people type a city into Open-Meteo Geocoding.
  • REST Countries: old versions were shut down and the new one needs a key. Use World Bank for country data, and https://flagcdn.com/w320/ke.png for flags (swap ke for any two-letter country code).
